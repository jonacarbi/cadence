How it works

Five steps, and you hold the fourth.

  1. 01

    Website

    Paste a client URL. Cadence reads the site for its colors, type, voice and audience.

  2. 02

    Brand system

    The extraction becomes a reusable brand system that every post is written and designed against.

  3. 03

    Month plan

    Pillars, a posting rhythm and platform-specific copy with branded visuals, day by day.

  4. 04

    Approval inbox

    Preview, edit, comment, regenerate. Nothing leaves until you approve it.

  5. 05

    Publish

    A scheduler posts through official APIs, honors caps and never blind-retries an unclear result.

Bring your own agent

Your agent writes. Its skills and memory come along.

Cadence does not ship a model. It drives the agent you already use, so your house style shapes every draft. Switch any time in Settings.

Safety

Posts like a careful person would.

  1. Official APIs only. No scraping, no password logins, no browser automation to post.
  2. Human approval. Review-everything is the default. Autonomy is a dial you turn yourself.
  3. Caps and spacing. A daily cap per account and a minimum gap between posts.
  4. Jitter and warm-up. A new account does not jump to full volume overnight.
  5. Fail closed. A blocked or revoked account pauses its lane; an unclear send is marked uncertain, never retried blind.

Lower risk, not zero risk.

No tool can guarantee an account is never limited. Cadence follows each platform's rules and you stay responsible for what you publish. Read the safety guide.

Local-first

Your clients stay on your machine.

Data
Brands, drafts and the database live in a folder you own.
Network
The server listens on loopback only.
Secrets
Account credentials are encrypted at rest and never returned by the API.
Egress
Text and images leave only for your chosen agent or a platform you connected.

Install

Running in four commands.

Needs Node 24 or newer (brew install node) and git. The native SwiftUI app is built with scripts/build-macos.sh on macOS 14 or newer.

Needs Node 24 or newer and git. node server/bin/cadence.mjs service install sets up a systemd user service so publishing runs without a window.

Needs Node 24 or newer (winget install OpenJS.NodeJS) and git. Run these in PowerShell. node server/bin/cadence.mjs service install registers a Task Scheduler logon task. Instagram, Facebook, Threads and TikTok sign-in also needs openssl (Git for Windows includes it).

git clone https://github.com/jonacarbi/cadence.git
cd cadence
npm run setup
npm start
# in a second terminal:
npm run open

npm run open opens the app in your browser, already signed in. Run node server/bin/cadence.mjs service install to keep publishing in the background, and npm run doctor if something does not work.

FAQ

Questions, answered plainly.

Is it free?

Yes. Cadence is MIT licensed. You pay only for the AI agent or API you choose and any platform fees, such as X API tiers.

Will it get my accounts banned?

It is designed to lower that risk: official APIs, human approval, caps, spacing, jitter and warm-up. No tool can promise zero risk, and you stay responsible for what you publish.

Where does my data go?

It stays on your machine. Prompts go to the agent you configure, and posts go to the platforms you connect. There is no Cadence cloud.

Do I need developer apps for every platform?

For Instagram, Facebook, Threads, LinkedIn, X, Pinterest, TikTok and Reddit, yes. Bluesky, Mastodon, Telegram and Discord need only a token or webhook.

Can my own agent use it?

Yes. Cadence exposes an MCP server so Claude Code or Codex can plan and comment. Approval stays with the owner token.

Does it run on Windows and Linux?

The server, CLI and browser interface run on macOS, Linux and Windows. The native SwiftUI app is macOS only.
